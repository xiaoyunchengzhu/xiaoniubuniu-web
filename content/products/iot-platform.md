# 小牛物联网平台

## 一句话介绍

面向中小制造企业的轻量级物联网设备管理平台，从设备接入到数据可视化一站式搞定。

## 解决的痛点

- 传统 PLC / 传感器数据停留在本地，无法远程监控
- 现有 IoT 平台（阿里云 IoT、AWS IoT）太贵、太复杂
- 中小企业没有技术能力自己搭建整套 IoT 系统

## 技术架构

```
设备层 (ESP32 / Raspberry Pi / DTU)
    ↓ MQTT / CoAP
消息中间件 (EMQX 集群)
    ↓
数据管道 (Spring Boot + Kafka Streams)
    ↓           ↓
时序数据库 (TDengine)   规则引擎
    ↓
可视化 (ECharts 大屏 + 告警推送)
```

## 核心功能

- **设备管理**：设备注册、认证、OTA 固件升级
- **数据采集**：MQTT / CoAP / HTTP 多协议接入，支持 10w+ 设备并发
- **规则引擎**：可视化配置告警规则，支持短信 / 微信 / 邮件通知
- **数据大屏**：实时数据展示、历史趋势、设备地理分布
- **API 开放**：RESTful API + WebSocket 实时推送，方便对接第三方系统

## 典型使用场景

1. 养殖场温湿度监控 → 自动控制风机/水帘
2. 工厂能源管理 → 电表/水表远程抄表
3. 冷库温度监控 → 超温自动告警

## 合作方式

- **私有化部署**：帮你部署到你自己的服务器
- **SaaS 订阅(等待开发)**：按设备数量/数据量付费
- **源码授权**：适合有自己技术团队想做二次开发的企业
